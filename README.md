
# HGNN-Attention-Recommender

Multi-domain recommendation using Heterogeneous Graph
Neural Networks with Attention.

## Datasets

- MovieLens Latest Small — Movie Recommendation
- JTH (Job Tracking History) — Job Recommendation

## Models

1. Popularity
2. Matrix Factorization (BPR)
3. XGBoost
4. LightGCN
5. HGNN without Attention
6. HGNN with Attention
